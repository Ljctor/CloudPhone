# 01 — Official Android Emulator and Google Play image

Install the official SDK under `/opt/android-sdk` and create the persistent AVD
under `/opt/android-avd`. The converged package set is:

```text
emulator 36.6.11 (build 15507667)
current compatible platform-tools
system-images;android-36;google_apis_playstore;x86_64
```

Create `slayer-google-test` with `avdmanager`, owned by `master`, from the
Android 16 Google Play x86-64 image. The service applies a 540×1170 skin, four
cores, 4 GiB of RAM and SwiftShader software rendering. Keep the AVD data: it
contains Android settings, the Google session, applications and game data.

## Check

```sh
: "${TARGET:?Set TARGET to setup-agent@SERVER_ADDRESS}"
ssh "$TARGET" 'sudo -n -u master sudo -n sh -eu' <<'REMOTE'
test -x /opt/android-sdk/emulator/emulator
/opt/android-sdk/emulator/emulator -version 2>&1 |
  grep -q 'Android emulator version 36\.6\.11\.0 (build_id 15507667)'
test -x /opt/android-sdk/platform-tools/adb
test -d /opt/android-sdk/system-images/android-36/google_apis_playstore/x86_64
test -f /opt/android-avd/slayer-google-test.avd/config.ini
grep -qx 'abi.type=x86_64' /opt/android-avd/slayer-google-test.avd/config.ini
grep -qx 'image.sysdir.1=system-images/android-36/google_apis_playstore/x86_64/' \
  /opt/android-avd/slayer-google-test.avd/config.ini
grep -qx 'hw.lcd.density=240' /opt/android-avd/slayer-google-test.avd/config.ini
grep -qx 'hw.keyboard=yes' /opt/android-avd/slayer-google-test.avd/config.ini
grep -qx 'hw.keyboard.lid=yes' /opt/android-avd/slayer-google-test.avd/config.ini
grep -qx 'hw.lcd.width=540' /opt/android-avd/slayer-google-test.avd/config.ini
grep -qx 'hw.lcd.height=1170' /opt/android-avd/slayer-google-test.avd/config.ini
test "$(stat -c %U:%G /opt/android-avd/slayer-google-test.avd)" = master:master
REMOTE
```

## Apply

Install Google's current command-line tools under
`/opt/android-sdk/cmdline-tools/latest`, then use `sdkmanager` as `master` to
accept the Android SDK licence and install:

```sh
sdkmanager=/opt/android-sdk/cmdline-tools/latest/bin/sdkmanager
sudo -u master "$sdkmanager" --sdk_root=/opt/android-sdk \
  'emulator' \
  'platform-tools' \
  'system-images;android-36;google_apis_playstore;x86_64'
```

Replace the current emulator package with Google's archived 36.6.11 Linux
build. This version is deliberately pinned because 37.1.11 segfaulted while
Google Play and WebRTC rendering were active.

```text
URL: https://redirector.gvt1.com/edgedl/android/repository/emulator-linux_x64-15507667.zip
SHA-256: 1eade4cf2df6ea8eeead4902c635897ba12aaa32aac4389eaae0fdb498a5b830
```

Verify the checksum before extraction. Preserve the `package.xml` generated by
`sdkmanager`, changing only its revision to `36.6.11`, and replace only
`/opt/android-sdk/emulator`. Never replace or delete `/opt/android-avd`: it is
the persistent Android disk.

Create the AVD as `master`:

```sh
avdmanager=/opt/android-sdk/cmdline-tools/latest/bin/avdmanager
printf 'no\n' | sudo -u master env ANDROID_AVD_HOME=/opt/android-avd \
  "$avdmanager" create avd \
  --force \
  --name slayer-google-test \
  --package 'system-images;android-36;google_apis_playstore;x86_64'
```

Set every `config.ini` value asserted by **Check**, recursively assign the
AVD to `master:master`, and rerun **Check** before installing the service.
